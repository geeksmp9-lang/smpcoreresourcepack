# Source of these textures

These crafting-station textures (block textures, GUI/container screens, particles, and
Patchouli guidebook icons) are copied from **Confluence: Otherworld**, a Terraria-inspired
NeoForge mod — not from Terraria itself.

- Mod: Confluence (`Confluence: Otherworld`), version 1.2.4
- License declared in the mod's `neoforge.mods.toml`: **GNU LGPL 3.0**
- Issue tracker / project link: https://github.com/Magic-team-jvav/confluence/issues

These are staged here as a reference/starting point for our own crafting-station art,
not a finished, original asset set — treat them as placeholders to trace/rework rather
than final textures, especially since this repo is public.
